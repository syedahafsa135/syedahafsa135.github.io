Loan default prediction

WEKA 3.8 · Python · scikit-learn · imbalanced-learn · Power BI

Which loans will default, and which technique finds them best?

Preprocessed 255,347 loans in WEKA, Python and Power BI, then compared Decision Tree, Naïve Bayes, MLP, Random Forest and AdaBoost in a leakage-free cross-validation pipeline with tuning and Friedman/Wilcoxon tests.

Key finding: tuned AdaBoost ranked first (test AUC 0.740, recall 0.659). Under an assumed 5:1 cost of a missed default, it cut total cost by about 21% compared with approving every loan.

Loan default risk in SQL

SQL (SQLite) · CTEs · window functions · Python · pandas · Matplotlib

Which borrowers default, in numbers a credit team can read?

Audited and cleaned 255,347 loans in SQLite, then answered 11 risk questions, one SQL file each: GROUP BY/HAVING basics, then CTE chains, moving averages, LAG, NTILE deciles, RANK within partitions and a Pareto cut. Five results were cross-checked in pandas, and all matched.

Key finding: four simple red flags take the default rate from 4.9% to 53.2%. Loans with two or more flags are 23.8% of the book but hold 47.4% of defaults.

Hotel booking statistics in R

R 4.6.1 · tidyverse · ggplot2 · hypothesis testing · regression

What drives room rates, and which bookings get cancelled?

Cleaned 119,390 bookings, then ran a Welch t-test, ANOVA with Tukey post-hoc tests, chi-square and multiple regression, reporting effect sizes beside every p-value. It finishes with a six-point memo for a CEO.

Key finding: adding season and a hotel × month interaction lifted explained variance in room rate from 22% to 55%. Market segment alone explains about 14% (η² = .141).

Real-time anomaly detection for CCTV

YOLO · OpenCV · Flask · React · Firebase · CVAT

Can a camera feed raise an alert the moment someone falls, a fire starts, a weapon appears or a fight breaks out?

Final year team project at NED University that detects fire, falls, weapons and fights in live video and logs each event for review.

My part:

  • Trained the fall and jump detection models on a 15,000+ image, 7-class dataset
  • Annotated video data in CVAT
  • Connected Firebase for live event logging

How it works: each detection model watches the live feed. When one fires, the app raises an alert and writes a timestamped event to Firebase for review after the incident.

Key finding: my 7-class fall and jump model (YOLO11n, 100 epochs) reached 0.72 recall and 0.58 mAP50 across all classes on its validation set.

Co-authored a research paper on the system with three teammates for a NED University journal: Automated Surveillance and Security System using Motion Transfer Technology for Real-Time Anomaly Detection.

Multiple disease prediction

Python · scikit-learn · Streamlit

Can simple health measurements flag diabetes or heart disease risk early?

A Streamlit web app with two trained classifiers: an SVM for diabetes and logistic regression for heart disease.

How it works: a sidebar switches between the two models, and input forms check that values are in range before predicting. I also implemented both algorithms from scratch to compare with the library versions. The from-scratch logistic regression reached 77.00% accuracy, against 88.52% for scikit-learn's.

Key finding: the heart model scored 0.89 accuracy and 0.91 recall on 61 test patients, but the diabetes model's 0.52 recall means it misses about half of diabetic cases.
