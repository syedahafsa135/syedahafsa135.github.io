# Syeda Hafsa | Data Analyst Portfolio

Live site: https://syedahafsa135.github.io

A one-page portfolio built with plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Structure

- `index.html` : page content
- `assets/css/style.css` : styles, including the light and dark themes
- `assets/js/main.js` : theme toggle, project filters, nav highlighting, copy-email button
- `assets/images/` : profile photo (`profile.jpg`) and any project screenshots
- `assets/Syeda_Hafsa_CV.pdf` : CV for the download button

## Projects

SQL, Power BI and Python projects, each framed around a business question. See the site for details.
